## 摘要
近期在4D高斯溅射（4DGS）方面的进展实现了高保真、实时的时空渲染，但揭示了运动表达力与存储效率之间的基本权衡。虽然基于锚定的设计通过锚定级参数共享实现紧凑性，但其刚性均匀参数化强制每个锚定具有固定的神经高斯数量和特征预算。因此，保真度不足是通过过度的锚定密度来解决的，而不是通过轻量级、有针对性的增加神经高斯数量或特征容量来解决，导致内存浪费。为克服这种刚性，我们引入了一种基于自适应容量锚定的框架，根据局部时空需求动态分配表示容量。自适应锚定基数（Adaptive Anchor Cardinality）改变每个锚定的神经高斯数量，将基元集中在几何或运动复杂度高的区域，同时抑制冗余。与此同时，自适应锚定特征掩码（Adaptive Anchor Feature Masking）调节锚定级特征通道，为复杂区域分配丰富特征，为简单区域分配轻量表示。在MPEG、Panoptic Sports和N3DV数据集上的实验表明，在不降低视觉质量的情况下实现了显著的存储减少。值得注意的是，在具有复杂运动的高难度MPEG序列上，我们的方法相比最先进的基于锚定的方法实现了高达1.5倍的更高压缩比，同时保持相当的质量。

## Abstract
Recent advances in 4D Gaussian Splatting (4DGS) enable high-fidelity, real-time spatiotemporal rendering, but expose a fundamental trade-off between motion expressiveness and storage efficiency. While anchor-based designs achieve compactness through anchor-level parameter sharing, their rigid uniform parametrization enforces fixed Neural Gaussian counts and feature budgets per anchor. Consequently, insufficient fidelity is addressed by excessive anchor density, rather than lightweight, targeted increases in Neural Gaussian count or feature capacity, resulting in memory waste. To overcome this rigidity, we introduce an adaptive-capacity anchor-based framework that dynamically allocates the representational capacity based on local spatiotemporal demands. Adaptive Anchor Cardinality varies the number of Neural Gaussians per anchor, concentrating primitives in regions of high geometric or motion complexity while suppressing redundancy. In parallel, Adaptive Anchor Feature Masking modulates anchor-level feature channels, assigning rich features to complex regions and lightweight representations to simpler ones. Experiments on MPEG, Panoptic Sports, and N3DV datasets demonstrate substantial storage reduction without degrading visual quality. Notably, on challenging MPEG sequences with complex motion, our method achieves up to 1.5x higher compression than state-of-the-art anchor-based methods while preserving comparable quality.

## 1. 核心问题与研究动机

- **4D 高斯溅射（4DGS）的固有矛盾**：动态场景渲染中，运动表达力与存储效率之间存在本质冲突。基于形变的方法难以精确捕捉快速运动；4D 基元方法虽能保持高质量，但为了捕捉复杂运动需要增加时间维度，导致存储量指数级增长。
- **锚定式方法的刚性缺陷**：新近的锚定式动态表示方法（如 GIFStream、ADC-GS）虽然通过锚定级参数共享实现了较高的紧凑性，但存在结构刚性问题——每个锚点被强制分配**固定的神经高斯数量（基数）**和**统一的特征通道数**，与局部场景复杂度无关。
- **资源错配问题**：在精细结构或复杂运动区域，固定基数迫使模型过度增加锚点数量来达到所需的高斯数量；在简单静态区域，固定分配又产生冗余基元和过大的特征容量，造成存储浪费。
- **核心研究问题**：如何打破锚定式方法中"每锚点固定容量"的结构刚性，根据局部时空复杂度动态分配表示资源，实现高保真渲染与极致紧凑存储的双重目标？

## 2. 方法论：自适应容量锚定框架

### 2.1 总体框架

基于 GIFStream 的锚定动态场景表示架构，每个体素化锚点生成固定数量（上界）的神经高斯，通过共享 MLP 解码锚点特征与时间特征来预测颜色、旋转、缩放、不透明度等属性。

### 2.2 自适应锚定基数（Adaptive Anchor Cardinality, AAC）

- **核心思想**：不再固定每个锚点的神经高斯数量，而是通过基于重要性的**重定位**（relocation）策略，将低重要性高斯从冗余区域迁移到高复杂度区域，在保持总高斯数量不变的前提下优化空间分布。
- **重要性度量**：由于锚定式高斯不存储独立的不透明度，而是由 MLP 按视图即时解码，仅看瞬时不透明度会产生视角偏差（某些视角下重要的基元在另一视角可能未被生成）。因此采用**跨视图累计不透明度**作为全局重要性分数：

  \[
  I_{i,k} = \sum_{t=1}^{T_R} \alpha_{i,k}^{(t)}(v_t)
  \]

  其中 \(T_R\) 为重定位间隔，累计过程在每次重定位后重置。
- **重定位流程**：按累计重要性排序，阈值 \(\tau\) 以下的基元标记为"失效"，在每次重定位中最多选取总数 \(\rho\%\)（默认 \(\tau=0.005\)、\(\rho=20\%\)）；通过重要性比例采样，从活跃基元中选取"父高斯"作为迁移目标；新位置通过父偏移加扰动初始化：

  \[
  o_{\text{new}} = o_{\text{parent}} + |o_{\text{parent}}| \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0, \delta^2 I)
  \]

- **基数门控策略**：为避免不同锚点数导致张量形状异构，采用**门控掩码**设计——MLP 仍预测固定最大值的高斯属性，但通过门控值 \(g_{i,k}\) 在渲染阶段控制激活，\(g_{i,k}\alpha_{i,k}\) 中值为 0 的基元不参与光栅化，从而保持批量并行处理流程。

### 2.3 自适应锚定特征掩码（Adaptive Anchor Feature Masking, AAFM）

- **核心思想**：不同区域对特征维度需求不同，精细区域需要丰富特征，平滑区域可降低特征容量。通过可学习掩码动态调节每锚点的有效特征通道。
- **分段因子化**：将锚点特征分解为基础段 \(F_{\text{base}}\) 与自适应段 \(F_{\text{adapt}}\)，仅对自适应段施加掩码，基础段全程保持激活，以维持优化稳定性。
- **掩码实现**：采用直通估计器（STE）学习二进制掩码：

  \[
  F_i = \text{concat}(F_i^{\text{base}},\ M_i F_i^{\text{adapt}}), \quad M_i = \text{sg}(\mathbb{1}[\sigma(m_i)>\gamma] - \sigma(m_i)) + \sigma(m_i)
  \]

- **掩码正则**：\(\mathcal{L}_M = \frac{1}{N}\sum_{i=1}^{N}\sigma(m_i)\)，鼓励自适应特征通道稀疏化，目标掩码率约 60%。

### 2.4 条件正则化损失（Conditional Regularization Loss）

- **动机**：单纯引入 AAFM 后，时间特征可能"越权"弥补空间特征缩减造成的表达损失，导致时空功能混淆、压缩效率下降。
- **公式**：

  \[
  \mathcal{L}_{CR} = \frac{1}{N}\sum_{i=1}^{N}\sigma(d_i)(1-\sigma(m_i))
  \]

  其中 \(d_i\) 为时间特征掩码参数。该损失在时间特征稀疏（静态/简单区域）时放宽空间特征缩减，在时间特征活跃（动态区域）时抑制掩码，保护时间特征的专用建模能力。

### 2.5 训练目标

\[
\mathcal{L} = \mathcal{L}_{\text{base}} + \lambda_M \mathcal{L}_M + \lambda_{CR} \mathcal{L}_{CR}
\]

其中 \(\mathcal{L}_{\text{base}}\) 包含渲染损失、压缩熵损失及 GIFStream 的正则项。训练完成后进行后处理剪枝，移除停用的高斯和掩码特征通道。

## 7. 方法亮点与优点

1. **问题定位精准**：直击锚定式 4DGS 的"结构性刚性"痛點，这个观察是准确的——固定基数和通道数的确是有悖于局部复杂度差异化的。
2. **重要性的跨视角设计巧妙**：锚定式高斯因无独立不透明度导致单视角重要性度量有偏，提出按重定位间隔累计多视角不透明度，方案简单有效；且重定位不增加总高斯数，避免额外内存开销。
3. **工程实现友善**：门控掩码设计在支持异构激活数量的同时保持固定形状张量和批量并行效率，解决了"变长结构"与"GPU 批次友好"的矛盾。
4. **防止功能混淆的正则化**：\(\mathcal{L}_{CR}\) 通过时间掩码与特征掩码的联合约束，巧妙防止空间/时间特征的角色蔓延，体现了对特征交互的深层理解。
5. **存储——质量平衡出色**：在 3.5–7.3 MB 的极小存储下维持了有竞争力的渲染质量，同时保持 80+ FPS 的实时性，贴近实际应用需求。

2. **时间特征掩码的交互未被消融**：论文设计了 \(d_i\)（时间掩码）与 \(m_i\) 的联合正则，但未单独消融时间掩码本身（GIFStream 已有）对 ACA-GS 的贡献。
3. **感知质量在小幅下降后未获解释**：在 Panoptic Sports 上 LPIPS 比 GIFStream 高 0.014、N3DV 上高 0.007，虽然 PSNR 几乎持平，但感知指标的下降在量化表中被简单带过，缺少定性分析解释原因。
4. **基数上界经验性较强**：表 4 显示基数=10 最优，但该值是否随场景规模/复杂度变化未有自适应策略或普适性验证。
5. **超参数默认值依赖经验调优**：\(\tau=0.005\)、\(\rho=20\%\)、\(\lambda_M\) 以"目标掩码率 60%"为标准——虽然敏感性分析显示鲁棒，但不同数据集是否需要重新调节仍未明确。
6. **论文场景规模有限**：仅验证了单场景短序列（N3DV、MPEG），对长视频、大规模场景、光照变化等复杂室外场景的泛化能力未知。

## 摘要
同时重建和理解3D环境对于具身智能体至关重要。为了实现这一目标，前馈语义3D高斯泼溅（3DGS）通过稀疏多视图观测高效构建语义场景表示。然而，现有方法缺乏显式的实例区分，主要支持基于类别或短语的语义查询。为此，我们提出GroupForward，一种实例分组的前馈高斯泼溅模型，能够从稀疏、无位姿且未标定的多视图图像中重建几何、外观、实例结构和语义。与现有方法将高维语义特征附加到每个高斯上不同，GroupForward学习紧凑的实例嵌入，将高斯分组为跨视图一致的3D实例，将前馈语义3DGS从每个高斯的语义特征渲染重新构建为实例级语义聚合与传播。基于这些实例分组，我们进一步提出一个参照场景推理框架（RSRF），用于复杂的3D引用分割。RSRF构建实例分组的3D场景图，并为给定的引用表达式检索候选实例。随后，一个视觉-语言模型基于结构化的实例证据和多视图观测进行推理，以识别候选实例中被引用的那个。因此，RSRF将语言交互从简单的语义查询扩展到复杂的参照场景推理。在语义重建和引用推理上的实验证明了我们实例分组重建与推理框架的有效性。

## Abstract
Simultaneously reconstructing and understanding 3D environments is essential for embodied agents. Toward this goal, feed-forward semantic 3D Gaussian Splatting (3DGS) efficiently constructs semantic scene representations from sparse multi-view observations. However, existing methods lack explicit instance discrimination and mainly support category- or phrase-based semantic queries. To this end, we propose GroupForward, an instance-grouped feed-forward Gaussian splatting model that reconstructs geometry, appearance, instance structure, and semantics from sparse, unposed, and uncalibrated multi-view images. Unlike existing methods that attach high-dimensional semantic features to each Gaussian, GroupForward learns compact instance embeddings that group Gaussians into cross-view consistent 3D instances, reformulating feed-forward semantic 3DGS from per-Gaussian semantic feature rendering to instance-level semantic aggregation and propagation. Building on these instance groups, we further propose a Referential Scene Reasoning Framework (RSRF) for complex 3D referring segmentation. RSRF constructs an instance-grouped 3D scene graph and retrieves candidate instances for a given referring expression. A vision-language model then reasons over structured instance evidence and multi-view observations to identify the referred instance among the candidates. RSRF thereby extends language interaction from simple semantic querying to complex referential scene reasoning. Experiments on semantic reconstruction and referential reasoning demonstrate the effectiveness of our instance-grouped reconstruction and reasoning framework.

### 2. 论文提出的方法论（核心思想、关键技术细节）

论文提出两个核心组成部分：**GroupForward**（实例分组的前馈高斯泼溅重建模型）与**RSRF**（参照场景推理框架）。

#### 2.1 GroupForward：实例分组的前馈高斯泼溅

- **实例嵌入的预测**：在标准前馈3DGS基础上（以VGGT为多视图编码器，几何解码器预测相机、深度、点图、法线），高斯解码器额外增加一个**实例头**，为每个像素对应的3D高斯预测紧凑实例嵌入 $e_{i,p} \in \mathbb{R}^{d_e}$，其中 $d_e=8$，远低于典型语义特征维度（如LSeg的512维）。
- **Gauge对齐自渲染（Gauge-Aligned Self-Rendering）**：在预测相机位姿下额外渲染上下文视图与目标视图，并通过比例因子 $\gamma$（基于共享上下文视图的平移向量范数比）对齐全局尺度，使重建场景与预测位姿之间保持一致，抑制位姿误差与场景几何之间的相互补偿。
- **渲染一致的实例学习**：采用两类损失：
  - **直接损失**：在上下文视图嵌入上计算拉近/推远损失（$L_{\text{pull}}^{\text{direct}}$ 和 $L_{\text{push}}^{\text{direct}}$），将嵌入拉向其L2归一化质心并推开不同实例质心。
  - **渲染损失**：将实例分配概率（通过softmax计算的高斯到实例的归属）作为辅助可渲染属性光栅化到上下文与目标视图，再用Dice损失、Focal损失以及渲染嵌入的拉近/推远损失监督，从而在3D渲染层面保证跨视图一致性。
- **语义聚合与传播**：推理时用HDBSCAN对上下文视图的嵌入聚类形成3D实例组；从冻结的2D开集语义模型中提取特征；对每个实例通过掩膜加权池化生成语义原型 $f^{\text{sem}}_k$；渲染实例分区并按其权重传播对应原型，从而为每个Gaussian免去高维特征存储。
- **分段课程训练**：分三阶段：
  1. 只训练重建（相机、几何、外观），实例头冻结；
  2. 冻结其余部分，仅训练实例头（模型支持用SAM2伪标签替代真实标注，并通过跨视图投影几何一致性建立跨视图实例关联）；
  3. 整体联合微调。

#### 2.2 RSRF：参照场景推理框架

- **3D场景图构建**：将每个实例组视为一个节点，包含语义原型、3D中心/范围/体积、2D投影和可见性；边编码有序实例对之间的3D距离、高度差、大小比和2D关系。
- **候选实例检索**：将自然语言表达解析为目标概念、目标基数、锚定实例、空间关系和视觉属性，结合语义相关性、几何相关性和跨视角可见性对节点排序，保留Top-K个候选（实验中 $K=8$）。
- **VLM推理**：为每个候选节点构造证据包（语义属性、几何属性、与邻居关系、跨视角可见性、多视图裁剪图），由Qwen3-VL-8B模型从候选节点中做闭集选择，直接映射到跨视图一致的3D掩膜，无需额外分割。

2. **跨视图身份一致性更稳定**：从定性结果上看，实例级语义聚合带来了更完整、更干净的语义区域与更清晰的边界。

### 7. 优点（方法或实验设计上的亮点）

- **简洁高效的核心设计**：用8维实例嵌入取代512维语义特征，大幅降低内存开销，却能在语义重建中实现更高精度，体现了“结构化表征比原始特征记忆更有效”的洞察。

- **将3D重建与语言推理桥接**：RSRF将引用分割问题转化为对3D场景图上候选节点的闭集选择，避开了不可靠的逐像素掩膜生成，输出天然是跨视角一致的3D结果。

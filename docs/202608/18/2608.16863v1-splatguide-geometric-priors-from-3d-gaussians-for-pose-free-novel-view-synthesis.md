## 摘要
从未标定图像生成逼真的新视图需要三维几何理解与合成未见内容的能力。一种自然的策略是将前馈式3D高斯泼溅重建与多视图扩散相结合。然而，现有的流水线最多从重建中提取一种信号，要么是像素渲染，要么是学习到的特征，没有方法利用每个高斯的可见性信息进行遮挡感知的参考视图选择。这种“信息断层”导致可渲染几何、可见性提示和学习到的特征未被充分利用。SplatGuide通过将单一的3D高斯泼溅场景复用于三个互补的角色来弥合这一断层：渲染图像提供像素对齐的几何条件；每个高斯的源视图索引被渲染为用于遮挡感知参考选择的目标视图投票图；重建token通过交叉注意力提供特征级指导。所有三种信号均来自同一次重建前向传播。在RealEstate10K、DL3DV、Tanks-and-Temples和Mip-NeRF 360数据集上，SplatGuide实现了最先进的无位姿新视图合成性能。在RealEstate10K上，在适度数量的输入视图下，它甚至超过了使用真实位姿的基线方法。

## Abstract
Generating photorealistic novel views from unposed images requires both 3D geometric understanding and the ability to synthesize unseen content. A natural strategy combines feed-forward 3DGS reconstruction with multi-view diffusion. Yet prior pipelines extract at most one signal from the reconstruction, either pixel rendering or learned features, while none exploits per-Gaussian visibility for occlusion-aware reference selection. This *information disconnect* leaves renderable geometry, visibility cues, and learned features unused. SplatGuide closes this disconnect by reusing a single 3DGS scene across three complementary roles. Rendered images provide pixel-aligned geometric conditioning. Per-Gaussian source-view indices are rendered into a target-view voting map for occlusion-aware reference selection. Reconstruction tokens supply feature-level guidance via cross-attention. All three signals derive from the same reconstruction forward pass. Across RealEstate10K, DL3DV, Tanks-and-Temples, and Mip-NeRF 360, SplatGuide achieves state-of-the-art pose-free novel view synthesis. On RealEstate10K, with a moderate number of input views, it surpasses the ground-truth-pose baseline.

## 1. 核心问题与整体含义（研究动机与背景）

**问题定义**：无位姿新视图合成（Pose-Free Novel View Synthesis, NVS）旨在仅凭一组未标定相机位姿的参考图像，在任意目标视角下生成逼真的新视图。该任务同时要求**三维几何理解**（重建场景结构）与**生成能力**（合成未见区域内容）。

**两大技术路线的割裂**：
- **前馈式重建模型**（如WorldMirror、AnySplat、NoPo-Splat）：单次前向传播即可恢复相机位姿和3DGS场景，但只能插值已观测视角，无法凭空生成未观测区域。
- **多视图扩散模型**（如SEVA、CAT3D）：能够生成照片级逼真的新视角，但依赖精确预计算的相机位姿，难以应用于无标定场景。

**核心痛点——"信息断层"（Information Disconnect）**：
尽管前馈重建已产出完整的3DGS场景（包含可渲染几何、逐高斯源视图归属、学习到的特征表示），现有结合重建与扩散的流水线普遍仅提取其中**一种信号**，其余信息全部丢弃：
- **姿态驱动方法**（CAT3D、SEVA）仅传递预测的相机参数，丢弃了整个重建场景；
- **像素级方法**（ViewCrafter等）仅渲染几何图像，受限于轨迹插值；
- **特征级方法**（Gen3C、Geometry Forcing）注入稠密潜特征，但计算成本高昂。

**关键洞察**：无位姿NVS的性能瓶颈不在于重建无法提供什么，而在于现有流水线**没有充分利用**重建已经提供的信息。其中，参考视图选择尤其依赖于现有方法普遍丢弃的**逐高斯可见性**——而选择策略的差异本身即可带来高达7 dB的质量差距。

**整体含义**：SplatGuide通过将单一的3DGS重建场景复用于三种互补角色（渲染图像、可见性投票图、重建token），系统性弥合重建与生成间的信息断层，实现了无需位姿、超越真实位姿基线的SOTA性能。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 总体架构

SplatGuide采用**重建→选择→生成**三阶段流水线，整体框架如下：

```
输入 N 张未位姿图像
  → 前馈重建模型（WorldMirror）输出：
      ① 3DGS场景（含逐高斯源视图索引）
      ② 估计的参考相机位姿
      ③ 相机token + 寄存器token
  → 可见性感知视图选择器（基于索引图投票）
  → 多视图扩散模型（基于SEVA）生成目标视图
```

### 2.2 三个互补的几何引导信号

**(1) 几何信号——渲染图像**

利用标准3DGS光栅化渲染管线，在目标位姿和参考位姿处渲染粗粒度但几何一致的图像：
$$\hat{I}_P = \sum_{k \in \mathcal{N}(P)} c_k \alpha'_k \prod_{l=1}^{k-1} (1 - \alpha'_l)$$
- 编码了重建场景的几何与外观，天然保持多视图一致性
- 通过**通道级拼接**注入扩散模型，保留像素对齐的空间对应关系
- 条件潜变量为：$z_{cond} = [z_t, z_{render}, e_{plk}, m]$

**(2) 可见性信号——逐高斯源视图索引投票图**

- 每个高斯天然携带其源视图索引$v(i)$（由构造决定，无需额外监督）
- 通过**首命中深度测试**渲染视角索引图：每个像素仅保留最近的高斯，写入对应源视图的调色板颜色
- 视线得分：$S(k) = \sum_p \mathbb{I}[\hat{v}(p) = k]$，统计每个候选视图解释的目标像素数
- 在可见性排序基础上增加两个轻量组件：
  - **DeDup**：过滤与已选视图空间冗余的候选，避免预算浪费在近似重复视角
  - **PoseAug**：最大化最孤立目标与上下文集的最小距离，确保每个目标至少有一个邻近上下文

**(3) 特征信号——重建token**

- 从重建骨干网络最后一层提取每个参考视图的**相机token**（用于位姿预测）和**4个寄存器token**（聚合非局部信息）
- 经线性投影后通过**交叉注意力层**注入扩散U-Net
- 提供像素级渲染无法传达的场景级上下文（全局结构、纹理统计）

### 2.3 训练目标

仅训练扩散模型，重建骨干和VAE全程冻结。采用标准潜空间扩散噪声预测目标：

$$\mathcal{L} = \mathbb{E}_{z_0, \epsilon, t} \left[ \| \epsilon - \epsilon_\theta(z_t, t, \mathcal{C}) \|_2^2 \right]$$

### 2.4 关键设计特点

- 三种信号均来自**同一次重建前向传播**，零额外3D图元
- 渲染图像为主要几何锚点；token提供补充的场景级上下文
- 视图选择器完全在生成器上游运行，与骨干网络解耦

## 6. 主要结论与发现

1. **信息断层的弥合带来显著增益**：在RealEstate10K上，SplatGuide比最强无位姿扩散基线（SEVA）提升**+3.05 dB**（3视图）；在9视图时**超越真实位姿SEVA**，证明完整框架可补偿预测位姿的精度损失。

2. **可见性感知选择是第一阶设计决策**：选择策略本身在B=6时产生**7 dB**的质量跨度；SplatGuide的混合策略在稀疏预算下比最强现有策略Surfel提升**+1.3 dB**，比CamDist提升**+3.9 dB**。

3. **三种信号互补而非替代**：渲染图像贡献最大单一增益（+0.66 dB），token进一步将LPIPS降低16%（相对基线）；两者协同优于各自单独使用。

4. **生成补足重建的固有限制**：SplatGuide超越纯重建基线5-7 dB，证明扩散生成在未观测区域的价值；域外场景增益持续，表明生成先验在重建退化时仍有效。

5. **模块化设计成立**：零样本将重建骨干从WorldMirror替换为AnySplat后性能不减反增（最多+1.29 dB），验证框架可随重建技术进展自动获益。

6. **候选池扩展单调增益**：池从32扩至128带来+1.15 dB PSNR提升，且调色板编码在V=128时无解码失败。

## 8. 不足与局限

**方法固有局限**：
- **错误相关性**：渲染、token、索引图全部来自同一个重建G，当骨干在无纹理表面、宽基线、重复结构等场景退化时，三类信号同时失真，生成器失去独立几何线索
- **动态场景失败**：运动既破坏重建质量，又打破索引图背后的首命中对应关系，是最尖锐的失败情况
- **架构绑定**：Plücker掩码输入布局和上下文窗口长度沿用SEVA设计，未验证其他多视图扩散骨干（如DiT架构）

**实验覆盖局限**：
- 训练数据仅两个数据集（RE10K、DL3DV），对极端域偏移（如夜间、水下、低光照）的泛化未充分验证
- 真实位姿SEVA的比较仅在部分设置下进行，未提供DL3DV上的真实位姿上限
- 自采挑战数据的定量比较缺少外部基准方法（如VMem、FoV等未在此数据集上报告）

**潜在偏差风险**：
- RayZer在DL3DV上的PSNR虚高虽被指出，但可能影响读者对排行榜的直接理解
- 候选池扩展到128以上（如256、512）的行为未验证，实用场景中池可能更大
- 推理成本分析在单卡上进行，未报告批量推理时的吞吐量表现

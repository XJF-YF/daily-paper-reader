## 摘要
前馈3D高斯泼溅无需逐场景优化即可实现高效的新视角合成，但大多数现有方法假定一组固定的上下文视图并对其进行联合处理。这限制了它们在标定视图按顺序到达且场景必须因果更新的在线场景中的适用性。我们提出了StreamSplat，一种流式前馈3DGS框架，它增量地维护一个持久的基于几何的场景状态，并在每个输入块之后将其解码为可渲染的3D高斯。StreamSplat的核心是一个体素对齐因果缓存，它将历史3D标记存储在内存有界的体素结构中，使得内存随探索的场景几何增长而非流长度增长。为了更好地在因果预测期间重用历史，我们引入了历史投影深度锚定，将缓存的几何投影为当前代价体积估计的深度指导，以及缓存引导的特征注入，将缓存的潜在证据注入高斯标记回归。在DL3DV、RealEstate10K和ScanNet上的实验表明，尽管不使用未来视图或全场景上下文，StreamSplat在稀疏因果输入下仍能与最先进的前馈3DGS方法保持竞争力。更重要的是，它可以扩展到具有256、512和1024个视图的长输入流，而固定视图基线会耗尽内存，随着更多观测的到来，新视角合成质量持续提高。代码将在接收后公开发布。

## Abstract
Feed-forward 3D Gaussian Splatting enables efficient novel-view synthesis without per-scene optimization, but most existing methods assume a fixed set of context views and process them jointly. This limits their applicability to online scenarios where calibrated views arrive sequentially and the scene must be updated causally. We present \emph{StreamSplat}, a streaming feed-forward 3DGS framework that incrementally maintains a persistent geometry-grounded scene state and decodes it into renderable 3D Gaussians after each input chunk. StreamSplat centers on a \textbf{Voxel-Aligned Causal Cache (VACC)}, which stores historical 3D tokens in a memory-bounded voxel structure so that memory grows with explored scene geometry rather than stream length. To better reuse history during causal prediction, we introduce \textbf{History-Projected Depth Anchoring (HPDA)} to project cached geometry as depth guidance for current cost-volume estimation, and \textbf{Cache-Guided Feature Injection (CGFI)} to inject cached latent evidence into Gaussian-token regression. Experiments on DL3DV, RealEstate10K, and ScanNet show that StreamSplat remains competitive with state-of-the-art feed-forward 3DGS methods under sparse causal inputs, despite not using future views or full-scene context. More importantly, it scales to long input streams with 256, 512, and 1024 views where fixed-view baselines run out of memory, yielding sustained improvements in novel-view synthesis quality as more observations arrive. The code will be made publicly available upon acceptance.

- **研究背景**：前馈式3D高斯泼溅（Feed-forward 3D Gaussian Splatting）能够在无需逐场景优化的情况下高效完成新视角合成，是近年来神经渲染领域的重要进展。
- **核心问题**：现有前馈3DGS方法大多**假设一组固定的上下文视图**，并对这些视图进行**联合处理**来重建场景。这种设计存在两个关键局限：
  1. **无法适应在线场景**：在真实应用中，标定好的相机视图通常是**按顺序到达**的（如机器人探索、自动驾驶、实时重建），场景状态需要随新观测进行**因果更新**，而固定视图方法要求一次性看到全部视图。
  2. **内存不可扩展**：固定上下文方法要么固定输入数量（如一次处理几张），要么将所有历史视图一起输入，导致内存随序列长度线性增长，无法处理长输入流。
- **整体意义**：作者提出 **StreamSplat**，这是**首个流式前馈3DGS框架**，它突破了“固定视图联合处理”的范式，使新视角合成能够以**因果、增量、内存有界**的方式处理任意长度的视图序列，从而将前馈3DGS推广到在线和长序列场景。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架

StreamSplat 维护一个**持久的、基于几何的场景状态**，每次输入一个“视图块”（chunk）后，增量更新该状态，并从中解码出可渲染的3D高斯。该框架的核心设计围绕三个关键组件展开。

### 2.2 体素对齐因果缓存（Voxel-Aligned Causal Cache, VACC）

- **作用**：存储历史3D标记（3D tokens），作为场景的持久几何表示。
- **关键特性——内存有界**：将历史3D标记存储在**体素结构**中，使内存占用与**已探索的场景几何**成正比，而非与**输入流长度**成正比。这意味着无论输入多少视图，缓存不会无限增长。
- **因果性**：只使用当前及过去的信息，不使用未来视图，符合在线场景的因果约束。

### 2.3 历史投影深度锚定（History-Projected Depth Anchoring, HPDA）

- **目的**：在因果预测过程中更好地复用历史信息。
- **做法**：将缓存中的历史几何投影到当前视角，作为当前代价体积（cost volume）估计的**深度引导（depth guidance）**。
- **效果**：为当前帧的深度估计提供先验，减少因缺少未来视图带来的不确定性，提升几何重建的稳定性。

### 2.4 缓存引导特征注入（Cache-Guided Feature Injection, CGFI）

- **目的**：让历史缓存的潜在证据参与当前高斯标记的回归。
- **做法**：将缓存中的潜在特征注入到高斯标记（Gaussian-token）的回归过程中，使当前生成的高斯能够利用历史观测的外观与几何信息。
- **效果**：增强高斯属性（位置、颜色、不透明度等）的预测质量，尤其是对当前视图中被遮挡或观察不充分的区域。

### 2.5 算法流程（文字描述）

1. 初始化一个空的体素对齐因果缓存 VACC。
2. 按顺序接收输入视图块（chunk）。
3. 对每个新块：
   - 提取当前视图的图像特征；
   - 利用 HPDA 将缓存中的历史几何投影为深度引导，与当前特征共同构建代价体积，估计深度；
   - 通过 CGFI 将缓存特征注入高斯标记回归网络，解码出当前块的3D高斯；
   - 更新 VACC，将新生成的3D标记写入体素缓存（若超出内存限制，按体素进行淘汰或合并，以保持内存有界）；
   - 输出当前场景的完整3D高斯表示，用于新视角渲染。
4. 重复上述步骤，直到流结束。
